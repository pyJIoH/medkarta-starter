# Медкарта

Личная медицинская карта на вашем компьютере: анализы, визиты к врачам, снимки, симптомы и лекарства в одном месте. Карту ведёт ИИ-ассистент, а вы читаете её на простом локальном сайте.

Что получится после настройки:

- **Обзор** — общая картина: что в порядке, за чем наблюдаем, что предстоит.
- **Кейсы** — симптомы, диагнозы и цели, которые вы ведёте; у каждого приоритет, история и следующий шаг. Прошло — закрыли.
- **Показатели** — все анализы и замеры с графиками; по клику — что это за показатель и что значат ваши цифры.
- **Записи** — анализы, визиты и сводки по датам, с оригиналами файлов.
- **План** — ближайшие визиты, анализы и задачи.

Ассистент — не врач. Он наводит порядок, объясняет простым языком и помогает подготовить вопросы к врачу. Диагнозы и лечение — за врачом.

## Что нужно

- Компьютер: Mac, Windows или Linux.
- **ИИ-ассистент, который умеет работать с файлами на компьютере**: Codex (приложение, расширение для редактора или командная строка), Claude Code, Cursor и подобные. Обычный чат в браузере не подойдёт — он не видит ваши файлы.
- [Node.js](https://nodejs.org) версии 20 или новее и git. Если их нет, ассистент подскажет, как поставить.

## Как начать

1. Скачайте заготовку: на странице репозитория — **Code → Download ZIP**. Распакуйте и положите папку туда, где она будет жить, — например в «Документы». Назвать её можно как угодно. **Не нажимайте Fork**: копия-форк на GitHub видна всем, а в карте будут ваши медицинские данные.
2. Откройте папку в своём ассистенте (в Codex — выберите её как рабочую папку).
3. Напишите ему:

   > Начни настройку

4. Отвечайте на вопросы. Ассистент пройдёт с вами шесть шагов: подготовка, о себе, откуда брать данные, что беспокоит сейчас, загрузка анализов и визитов, первая сводка. Это 30–60 минут; можно делать по частям — он помнит, где остановились.
5. Сайт откроется по адресу http://localhost:3737.

Что стоит подготовить заранее:

- входы в личные кабинеты клиник и лабораторий;
- файлы с анализами и заключениями, если они есть на компьютере;
- список лекарств и добавок с дозами;
- что вас беспокоит — хотя бы списком.

## Как пользоваться потом

| Что случилось | Что сделать |
|---|---|
| Новые анализы или визит | Сохранить файлы в папку `inbox/` или перетащить на сайт, затем написать ассистенту: «разбери inbox» |
| Что-то заболело | Кнопка «Заметка» на сайте — или просто рассказать ассистенту |
| Симптом повторился | Открыть кейс на сайте → «Записать эпизод» |
| Прошло | Открыть кейс → «Закрыть кейс» |
| Изменился вес или давление | Написать ассистенту цифру |
| Хочется общей картины | «Сделай сводку» |
| Сайт не открывается | «Запусти сайт» |

Ассистенту можно задавать вопросы по карте: «что у меня с железом за два года?», «подготовь вопросы к терапевту».

## Приватность — прочитайте это

- **Файлы лежат только на вашем компьютере.** Сайт работает локально и недоступен из интернета.
- **Ассистент — это облачный сервис.** Всё, что он читает, чтобы вам помочь, передаётся компании, которая его делает. Перед началом загляните в настройки своего аккаунта и решите, разрешать ли использовать ваши данные для обучения моделей. Не ведите карту через рабочий аккаунт.
- **Резервная копия на GitHub — по желанию и только в приватном репозитории.** Ассистент спросит об этом на первом шаге.
- Папка `inbox/` с сырыми файлами в резервную копию не попадает.

## Что внутри

```
AGENTS.md      правила для ассистента — он читает их сам
docs/          сценарий настройки, форматы файлов, справка по источникам данных, образцы
profile.md     о вас
cases/         кейсы
records/       записи: анализы, визиты, сводки
metrics/       таблицы показателей
plan.yaml      план
inbox/         входящие
settings.yaml  настройки сайта (необязательно)
site/          сайт
```

Править файлы руками не нужно: это делает ассистент, а часть действий — сам сайт. Но всё хранится в обычных текстовых файлах, их можно открыть и прочитать без всяких программ.

## Сайт отдельно от данных

По умолчанию всё лежит в одной папке, и это самый простой вариант. Если вы хотите получать обновления сайта из этого репозитория, а карту держать в своём приватном, их можно разделить: сайт читает данные из любой папки.

```
моя-карта/            ваш приватный репозиторий: profile.md, cases/, records/, metrics/, plan.yaml
  medkarta/           этот репозиторий, вложенной папкой (git submodule или обычный clone)
```

```
node medkarta/site/server.mjs --root .     # сайт
node medkarta/site/check.mjs --root .      # проверка данных
```

Вместо `--root` можно задать переменную `MEDKARTA_ROOT`. В папку самого сайта при этом ничего не пишется: заметки и загрузки попадают в `inbox/` вашей карты.

## Если что-то пошло не так

Напишите ассистенту: «проверь карту». Он запустит проверку данных и исправит то, что найдёт.
